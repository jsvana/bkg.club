# BKG Discord Rules — copy/paste kit

Paste-ready text for the BKG Discord rules channel. Each block below is one
Discord message (each fits Discord's 2000-character limit, no Nitro needed) —
use the copy button on each block and paste straight into Discord. The
`**bold**`, `#` headers, and `>` quote render natively in Discord.

Post them in order: profile format first, then the rules.

## Message 1 — the accepted profile format

```text
# 🤜 FIRST ORDER OF BUSINESS: UR PROFILE 🤜

B4 u post a single word, set ur **per-server profile** (tap the server name → **Edit Server Profile**) 2 the accepted format:

**Name | Call | BKG#**

🏅 **State & Country OGs** — the first brass pounder pounded in from a state or DX country — may add **| (State) OG** after the BKG#. That badge was EARNED!! Everyone else: three slots, that's it!!

**LIVE EXAMPLE:**
> Justin | N9HO | #32 | AL OG

**The slots:**
- **Name** — ur first name. The one ur elmer calls u.
- **Call** — ur callsign. Wear it proud!!
- **BKG#** — ur gang number, with the # in front (like #32). Forgot it? It's on the roster at bkg.club!!
- **(State) OG** — OPTIONAL!! State & Country OGs ONLY!! Not an OG? Leave it off!!

🚨 **PLZ make sure u do NOT stray from the accepted profile name or add additional info!!** No extra emojis, no titles, no "aka", no freelance flair — the format IS the flair!! 🚨
```
